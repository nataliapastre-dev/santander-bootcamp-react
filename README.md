# 🚀 Santander Bootcamp React

## 📖 Sobre o Bootcamp

Este repositório reúne as atividades desenvolvidas durante o **Santander Bootcamp React**, uma jornada de aprendizado focada em desenvolvimento Front-End moderno utilizando React, JavaScript, Vite, Inteligência Artificial e boas práticas de desenvolvimento de interfaces.

O programa tem como objetivo capacitar desenvolvedores para criar aplicações web modernas, responsivas e centradas na experiência do usuário, combinando fundamentos sólidos de programação com tecnologias amplamente utilizadas no mercado.

---

## 🎯 O que estou aprendendo

Durante o bootcamp, estou desenvolvendo conhecimentos e habilidades em:

* React 19
* JSX
* Componentes Funcionais
* Hooks
* Gerenciamento de Estado
* JavaScript Moderno (ES6+)
* HTML5
* CSS3
* Vite
* Design Responsivo
* UI/UX Design
* Boas Práticas de Desenvolvimento
* Integração com APIs
* Inteligência Artificial aplicada ao desenvolvimento web
* Controle de versão com Git e GitHub

---

## 📚 Atividades do Bootcamp

### 🎥 Cursos

Aulas em vídeo objetivas e práticas que apresentam conteúdos de forma gradual, permitindo o aprendizado no próprio ritmo e a consolidação dos conhecimentos através de avaliações.

### 🎙️ Mentorias

Encontros ao vivo com especialistas do mercado para aprofundar conhecimentos, esclarecer dúvidas e compartilhar experiências profissionais.

### 💻 Desafios de Código

Exercícios práticos que estimulam o raciocínio lógico, a resolução de problemas e a aplicação dos conceitos aprendidos.

### 🛠️ Desafios de Projeto

Projetos completos desenvolvidos para aplicar os conhecimentos adquiridos em situações reais, contribuindo para a construção de portfólio profissional.

### 🤖 Desafios de Criação

Atividades que utilizam Inteligência Artificial Generativa para estimular criatividade, inovação e desenvolvimento de soluções para desafios do cotidiano.

---

## 🧰 Ferramentas de Aprendizado

O bootcamp também oferece recursos para acompanhar a evolução dos participantes:

* 📅 **Meta de Estudo** para planejamento da rotina de aprendizado.
* 🏆 **Ranking** baseado em desempenho e participação.
* 💬 **Fórum** para troca de conhecimento e esclarecimento de dúvidas.
* 👥 **Rooms** para interação em tempo real com outros participantes.
* 🌐 **Networking** através da comunidade do programa.
* 📜 **Certificados** de conclusão e desenvolvimento de habilidades.

---

## 🎯 Meu Objetivo

Através deste bootcamp, busco aprimorar minhas habilidades em Desenvolvimento Front-End, fortalecer meus conhecimentos em React e expandir minha experiência prática na construção de aplicações modernas e eficientes.

Este repositório servirá como registro da minha evolução e aprendizado ao longo da jornada.
