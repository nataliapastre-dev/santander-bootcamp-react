

# 🚀 Santander Bootcamp React

Repositório dedicado aos desafios, exercícios e projetos desenvolvidos durante o Santander Bootcamp React.

## 📚 Sobre

Este repositório reúne as atividades realizadas ao longo do bootcamp, incluindo desafios de código, projetos práticos e estudos voltados ao desenvolvimento Front-end com React.

## 🛠️ Tecnologias Utilizadas

* JavaScript
* React
* HTML5
* CSS3
* Git
* GitHub
* Vite

## 🎯 Objetivo

Praticar lógica de programação, desenvolvimento Front-end e conceitos fundamentais do React, aplicando os conhecimentos adquiridos ao longo do bootcamp por meio de desafios e projetos práticos.
